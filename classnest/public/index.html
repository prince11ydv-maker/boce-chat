    Instructions for Android and iPhone

    Android

    Open Classnest in Chrome. Tap the browser menu (⋮), choose Install app or Add to Home screen, then confirm.

    Download Android APK
    For Android 8.0 and newer. iPhone uses the home-screen app below.

    iPhone or iPad

    Open Classnest in Safari. Tap Share, then Add to Home Screen. Keep Open as Web App on if it is shown, then tap Add.

    Internet is needed to load class content. Turn on phone alerts in Notifications in a supported browser or home-screen app. The Android APK uses its app menu to enable phone alerts. Email updates have separate preferences.
